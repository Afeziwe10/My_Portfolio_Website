# Afeziwe Thandani — Portfolio

A personal portfolio website showcasing my background, skills, projects, and
certificates, with ways to get in touch.

## Pages

- `index.html` — Home page, introduction, skills, featured projects,
  certificates, and contact links.
- `about.html` — About page.
- `projects.html` — Project gallery with filters for web, desktop, and mobile
  projects.
- `contact.html` — Contact page.

## Projects

The portfolio currently features:

- Xclusive Society
- Cybersecurity Chatbot
- Contract Monthly Claim System
- MyBudgetPro
- Gift of the Givers
- MyCampusComp
- HerMentor

Project cards link to their corresponding GitHub repositories. Project images
and other visual assets are stored in `Images/`; certificate images are in
`Certificates/`.

## Technology

- HTML, CSS, and JavaScript
- Font Awesome 6.7.2 via CDN
- No build step or package installation is required

## Run locally

Open `index.html` in a browser, or serve the project directory with a local
static web server. For example, if Python is installed:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

The site uses relative paths for its local CSS, JavaScript, images, and pages,
so keep the files and asset folders in their current structure.
